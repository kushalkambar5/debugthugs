# AI Digital Twin Medical Models API

This repository contains the backend FastAPI application that serves 6 medical AI models for disease detection.
It has been configured for easy local setup.

## Prerequisites

- Python 3.9 or higher (tested up to 3.10/3.11)
- [Git LFS](https://git-lfs.com/) installed (to download the large `.pt` and `.pth` model weights)

## Setup Instructions

1. **Clone the repository (make sure Git LFS is installed first!):**
   ```bash
   git clone <YOUR_GITHUB_REPO_URL>
   cd debugthugs/"Ai models part"
   ```

2. **Create a virtual environment (recommended):**
   ```bash
   python -m venv venv
   
   # On Windows:
   venv\Scripts\activate
   
   # On Mac/Linux:
   source venv/bin/activate
   ```

3. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## Running the Application

Start the FastAPI server using Uvicorn:

```bash
uvicorn app:app --port 8000 --reload
```

## Testing the API

Once the server is running, you can test all the models through the interactive Swagger documentation page automatically generated by FastAPI.

Open your browser and navigate to:
**http://localhost:8000/docs**

There you can easily upload images (for Bone, Brain, Chest, Skin) or enter JSON data (for Heart, ECG) and test the predictions directly in the browser.

## Models Included

1. **Bone Fracture Detection** (YOLOv8)
2. **Brain Tumor Detection** (YOLOv8)
3. **Chest X-Ray Pathology** (TorchXRayVision DenseNet)
4. **Skin Disease Detection** (YOLOv8)
5. **ECG Arrhythmia Classification** (Custom 1D-CNN)
6. **Heart Disease Risk** (XGBoost)
